## 3. Le défaut : l'édition du 30 août est publiée sur un seul modèle

```
2026-08-30  runs=50   réponses=98   annoncés=[chatgpt,gemini]  ont répondu=[gemini:98]  ⚠ chatgpt : 0
2026-08-23  runs=100  réponses=196  annoncés=[chatgpt,gemini]  ont répondu=[chatgpt:98, gemini:98]
2026-08-16  runs=100  réponses=196  annoncés=[chatgpt,gemini]  ont répondu=[chatgpt:98, gemini:98]
```

Les 50 appels ChatGPT ont échoué un par un, chacun avalé par le `catch` de `runJobs`.
Ce `catch` est écrit pour qu'un appel raté n'invalide pas une édition ; il a laissé
passer un provider entier. Confirmation par la dépense : **0,2318 $** le 30 août contre
1,47 $ le 23 — aucun appel OpenAI n'a abouti.

Trois conséquences, toutes en ligne aujourd'hui sur `/barometre` :

**Le site annonce deux modèles pour une mesure faite sur un seul.** `data.models`
enregistre les providers visés, pas ceux qui ont répondu.

`runs` est passé de 100 à 50. Cinq marques ont changé de palier sans qu'une seule
